Shorts upload checklist

Recommended publishing settings

Audience: Choose “made for kids” only if the video is actually directed to children.

Visibility: Public or scheduled after reviewing all settings.

Shorts: Upload vertical video; YouTube classifies eligible Shorts automatically.

Tags: Use a small set of precise tags; tags are not a viral switch.

Hashtags: Use a few relevant ones, not a long unrelated list.

Audio: Prefer YouTube Shorts audio library or properly licensed audio.

There is no secret setting that guarantees viral reach. Viewer satisfaction, retention, swipe behavior and topic fit matter.

Post-publish review

Paste metrics from YouTube Studio after enough time has passed for data to stabilize.

What to improve

  • Low viewed rate → test a stronger opening frame and immediate context.
  • Good viewed rate, weak retention → shorten setup and remove dead time.
  • Strong retention, low reach → test topic demand and repeatable audience fit.
  • Review audience retention graph in YouTube Studio to find exact drop-offs.

Techveta: open-source MVP

This downloadable prototype runs in your browser and does not send your data to a server. It generates suggestions from the information you enter. Live channel import, automatic analytics, and applying metadata to published videos require a secure OAuth app and API access. YouTube API has quotas; vidIQ/TubeBuddy free plans also have their own feature or credit limits. Google Trends API access is currently limited alpha, so this prototype opens the free Trends website instead.

Always review the suggested title, description, tags and audience settings before applying. Automated edits should ask for your confirmation.
